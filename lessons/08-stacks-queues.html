Lesson 08 · Linear structures

Stacks & queues

Two simple structures with one rule each. A stack: the last thing in is the first out (LIFO). A queue: the first thing in is the first out (FIFO). The rule is the whole point — it tells you which item to deal with next.

🎯 After this lesson you can
  • use a list as a stack and a deque as a queue, with O(1) operations
  • recognise "stack problems": matching, nesting, undo, "previous/next greater"
  • use a monotonic stack
  • solve LeetCode 20, 155, 844, 150, 232, 933, 739, 394

1. The real-life picture

📚 Stack = a pile of plates

You put plates on top and take from the top. Undo (Ctrl+Z), the browser's back button, and Flutter's Navigator.push / pop are stacks!

🚶 Queue = a line at the bank

New people join at the back, the person at the front is served first. Print jobs, messages, and BFS in graphs (lesson 15) are queues.

2. In Python

stack = a list
stack = []
stack.append(1)      # push      O(1)
stack.append(2)
top = stack[-1]      # peek      O(1)
x = stack.pop()      # pop → 2   O(1)
if stack: ...        # not empty?
queue = a deque
from collections import deque
q = deque()
q.append(1)          # join at back   O(1)
q.append(2)
front = q[0]         # peek           O(1)
x = q.popleft()      # leave → 1      O(1)
if q: ...            # not empty?
Dart → Python Dart's List works as a stack (add/removeLast), and Queue from dart:collection is a deque (addLast/removeFirst). In Python, never use list.pop(0) as a queue — it's O(n) (lesson 03).

3. 👀 Stack: matching brackets

The bracket opened last must close first. Whenever "the most recent unfinished thing" matters, think stack.

4. 👀 Queue: first come, first served

Jobs take turns: each gets 2 units of time, and if it isn't finished it goes to the back of the line.

5. 👀 The monotonic stack

"For each day, how long until a warmer day?" Brute force looks forward from every day: O(n²). Better: days that are still waiting sit on a stack. When a warmer day arrives, it answers every waiting day that is colder (popping them). The stack's temperatures always go down from bottom to top — that's why it's called monotonic.

🧩 Template: monotonic stack ("next greater") 
answer = [default] * n
stack = []                                   # indexes still waiting
for i, x in enumerate(nums):
    while stack and nums[stack[-1]] < x:     # x answers the smaller ones
        j = stack.pop()
        answer[j] = ...                      # e.g. i - j, or x
    stack.append(i)

Signals: "next greater / smaller element", "days until", "stock span", "largest rectangle", "remove digits to make the smallest number".

🧩 When to use which

Stack signals: matching pairs, nesting (3[a2[c]]), undo / backspace, "most recent", evaluate expressions, DFS without recursion.

Queue signals: "in order of arrival", process level by level, BFS / shortest steps, "the last N seconds", round robin.

7. 📌 Summary

  • Stack: append / pop() / [-1] on a list. Queue: append / popleft() on a deque. All O(1).
  • Stacks handle "most recent first": matching, nesting, undo. Queues handle "oldest first": order of arrival, BFS.
  • Monotonic stack: each item is pushed once and popped once → O(n) for "next greater" problems.
