Lesson 07 · Core pattern

Prefix sums

Pay once, answer forever. Build a list of running totals in O(n), and then the sum of any section is a single subtraction. Combined with a dict (lesson 04), it solves "count the sections that sum to k" — even with negative numbers.

🎯 After this lesson you can
  • build a prefix list and get any range sum in O(1)
  • use the "prefix + dict" pattern (Two Sum's big brother)
  • use prefix products, and 2-D prefix sums

1. The real-life picture

Your car's odometer shows the total km since it was new. How far did you drive between Kandy and Colombo? You don't add up every km — you take odometer at Colombo − odometer at Kandy. A prefix list is an odometer for your list.

2. 👀 Build it, use it

prefix[i] = sum of the first i numbers. So prefix[0] = 0 and the list is one longer than nums. That extra 0 removes all special cases.

🧩 Template: prefix sums 
prefix = [0] * (len(nums) + 1)
for i, x in enumerate(nums):
    prefix[i + 1] = prefix[i] + x

# sum of nums[left..right] (both included):
total = prefix[right + 1] - prefix[left]

Signals: "sum of range / subarray", many queries on a list that doesn't change, "left sum equals right sum", "running total".

3. 👀 Prefix sums + dict: counting sections

"How many sections sum to exactly k?" The section from i to j has sum P[j] − P[i]. We want P[j] − P[i] = k, i.e. P[i] = P[j] − k. So while walking, at each position ask a dict: how many earlier prefixes equal current − k? That's exactly Two Sum's "complement" idea!

🧩 Template: prefix + dict 
seen = {0: 1}          # prefix value → count  (or → first index, for "longest")
running = 0
for x in nums:
    running += x
    answer += seen.get(running - k, 0)
    seen[running] = seen.get(running, 0) + 1

Signals: "number of subarrays with sum k", "longest subarray with sum k", negative numbers allowed, "equal number of 0s and 1s" (turn 0 into −1).

Window or prefix? All numbers positive and you want longest/shortest with sum ≥ / ≤ something → sliding window (O(1) space). Negative numbers, or "exactly k", or "how many" → prefix sums + dict.

4. Variations

  • Prefix products: product of everything except index i = (product on the left) × (product on the right). Practice problem 5.
  • 2-D prefix sums: the sum of any rectangle in a grid in O(1). Practice problem 7.
  • Difference arrays (the reverse idea): to add a value to a whole range many times, add at the start, subtract after the end, and take a prefix sum at the end.

6. 📌 Summary

  • prefix[i] = sum of the first i items; range sum = prefix[r + 1] − prefix[l].
  • Prefix + dict counts or measures sections with a given sum in O(n), negatives allowed.
  • The same idea works for products, 2-D grids, and counts.
