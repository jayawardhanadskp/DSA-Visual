Heaps & priority queues

A heap answers one question very fast: "what is the smallest item right now?" — even while items keep arriving and leaving. It's the engine behind "top k", "k-th largest", scheduling, merging sorted lists, and Dijkstra's shortest path (next lesson).

1. The real-life picture

A hospital emergency room isn't first-come-first-served: the most urgent patient goes first. That's a priority queue. A heap is the data structure that makes "add a patient" and "take the most urgent one" both O(log n).

Structureaddget & remove the smallest
unsorted listO(1)O(n) — search everything
sorted listO(n) — shift to insertO(1)
heapO(log n)O(log n) (and peeking is O(1))

2. A tree hiding in a list

A (min-)heap is a binary tree with one rule: every parent is ≤ its children. So the smallest item is always at the top. The tree is always filled level by level, left to right, so it fits perfectly in a list with no pointers:

index:    0  1  2  3  4  5          children of i:  2*i + 1 and 2*i + 2
heap:   [ 1, 3, 2, 5, 9, 8 ]        parent of i:    (i - 1) // 2

              1           ← heap[0]: always the smallest
            /   \
           3     2
          / \   /
         5   9 8

It is not sorted (3 is before 2) — only the parent/child rule holds. That's why it's cheaper to maintain than a sorted list.

3. 👀 Push: bubble up

Put the new item at the end (the next free spot), then swap it with its parent while it's smaller. At most one swap per level → O(log n).

4. 👀 Pop: sink down

Take the top. Move the last item to the top (to keep the shape), then swap it with its smaller child while it's bigger. O(log n).

5. In real Python: heapq

You never write push/pop yourself — heapq does exactly the above on a normal list.

import heapq
heap = []
for x in [5, 3, 8, 1, 9, 2]:
    heapq.heappush(heap, x)
print(heap, heap[0])                  # heap[0] = smallest (peek, O(1))
print(heapq.heappop(heap), heap)      # pops 1

nums = [7, 2, 9, 4]
heapq.heapify(nums)                   # list → heap in O(n), in place
print(nums)

# max-heap: push negatives
mx = []
for x in [5, 3, 8]:
    heapq.heappush(mx, -x)
print(-heapq.heappop(mx))             # 8

# priorities with tuples: (priority, item) — compared item by item
tasks = []
heapq.heappush(tasks, (2, "write tests"))
heapq.heappush(tasks, (1, "fix bug"))
heapq.heappush(tasks, (3, "coffee"))
print(heapq.heappop(tasks))           # (1, 'fix bug')

print(heapq.nlargest(2, [4, 1, 7, 3]), heapq.nsmallest(2, [4, 1, 7, 3]))
Dart → Python Dart has PriorityQueue in package:collection with a comparator. Python's heapq is always a min-heap on a plain list; use negatives for max, and tuples for "priority + data".

6. 👀 Pattern: heap of size k

To find the k largest items, keep a min-heap of size k: whenever it grows past k, pop the smallest. At the end it holds the k largest, and heap[0] is the k-th largest. O(n log k), and it works on a stream that never ends.

🧩 Heap templates 
# k largest (min-heap of size k)
heap = []
for x in items:
    heapq.heappush(heap, x)
    if len(heap) > k:
        heapq.heappop(heap)

# repeatedly take the best (max-heap via negation)
heap = [-x for x in items]; heapq.heapify(heap)
while heap:
    best = -heapq.heappop(heap)

8. 📌 Summary

  • A heap = a complete binary tree in a list; parent ≤ children; the minimum is heap[0].
  • push / pop are O(log n), peek O(1), heapify O(n).
  • Max-heap: negate. Priorities: tuples. Top k: heap of size k. Median: two heaps.
