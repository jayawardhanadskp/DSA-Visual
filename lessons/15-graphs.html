Lesson 15 · Trees & graphs

Graphs

A graph is things (nodes) and connections (edges): cities and roads, users and friendships, courses and prerequisites, cells in a grid and their neighbours. A tree is just a graph without cycles. You already know the two main tools — DFS and BFS — and now you'll add a visited set and three famous algorithms.

🎯 After this lesson you can
  • turn any input (edge list, matrix, grid) into something you can traverse
  • use BFS (shortest steps), DFS (explore / count groups), topological sort (dependencies), Dijkstra (weighted shortest path) and union-find (groups)
  • solve LeetCode 200, 733, 1971, 547, 207, 210, 994, 1091, 743, 323

1. How a graph is stored

FormPythonWhen
Adjacency list (the usual one)graph = {"A": ["B", "C"], "B": ["A"], …}almost always — you can loop over a node's neighbours
Edge list (how inputs often arrive)edges = [[0, 1], [1, 2]]convert it to an adjacency list first
Adjacency matrixm[i][j] == 1 if connectedsmall dense graphs; some LeetCode inputs
Grid (implicit graph)grid[r][c] + 4 directionsmazes, islands, flood fill
from collections import defaultdict
edges = [[0, 1], [1, 2], [3, 4]]
graph = defaultdict(list)
for a, b in edges:          # undirected: add both directions
    graph[a].append(b)
    graph[b].append(a)
print(dict(graph))
# directed (a → b): only graph[a].append(b)
# weighted: graph[a].append((b, weight))

Words: directed (one-way arrows) or undirected; weighted (edges have costs); a cycle is a path back to where you started; a connected component is a group of nodes that can reach each other.

2. 👀 BFS — shortest number of steps

Exactly the tree BFS from lesson 13, plus one thing: graphs can have cycles, so remember which nodes you've seen (here the dist dict does that). BFS reaches nodes in order of distance: first everything 1 step away, then 2 steps…

🧩 Template: BFS 
from collections import deque
seen = {start}
queue = deque([start])
while queue:
    node = queue.popleft()
    for nei in graph[node]:
        if nei not in seen:
            seen.add(nei)              # mark when ADDING, not when popping
            queue.append(nei)

3. 👀 DFS — explore everything reachable

Go deep first, back up when stuck. The purple nodes are the current path on the call stack.

🧩 Template: DFS 
visited = set()
def dfs(node):
    visited.add(node)
    for nei in graph[node]:
        if nei not in visited:
            dfs(nei)

# count connected groups = count how many times you START a new dfs
groups = 0
for node in graph:
    if node not in visited:
        dfs(node)
        groups += 1

4. 👀 Grids are graphs

Each cell is a node; its up/down/left/right neighbours are its edges. You never build the graph — the directions list from lesson 03 gives the neighbours. Here "visited" is done by changing the cell to "#".

5. 👀 Topological sort — order with dependencies

Courses with prerequisites form a directed graph (an arrow from "before" to "after"). An order that takes every course after its prerequisites is a topological order. Kahn's algorithm: count how many prerequisites each course still waits for; repeatedly take a course that waits for nothing. If you can't take all courses, there's a cycle (A needs B, B needs A).

6. 👀 Dijkstra — shortest path with weights

When edges have different costs, BFS isn't enough. Dijkstra is BFS with a heap instead of a queue: always continue from the closest unfinished node. Below, A → B directly costs 4, but A → C → B costs 3.

🧩 Template: Dijkstra 
import heapq
dist = {start: 0}
heap = [(0, start)]
while heap:
    d, node = heapq.heappop(heap)
    if d > dist[node]:
        continue                     # stale entry
    for nei, w in graph[node]:
        if d + w < dist.get(nei, float("inf")):
            dist[nei] = d + w
            heapq.heappush(heap, (d + w, nei))

O((V + E) log V). Weights must not be negative.

7. 👀 Union-find — which group am I in?

Every item points to a "boss"; following the bosses up leads to the group's root. Joining two groups = making one root the boss of the other. Great when connections arrive one by one, or to detect a cycle in an undirected graph (union of two items already in the same group).

8. Which graph tool?

The problem says…Use
fewest steps / moves / minimum number of …, all steps cost the sameBFS
count islands / groups / provinces, can I reach…, explore everythingDFS (or BFS)
prerequisites, dependencies, order of tasks, "is there a cycle" (directed)Topological sort
cheapest / fastest path, weights on edgesDijkstra
connections added over time, "are these connected?", redundant edgeUnion-find
spreading from many places at once (fire, rot, infection)Multi-source BFS

10. 📌 Summary

  • Build an adjacency list first. Grids are graphs with a directions list.
  • Always keep a visited set (or mark cells).
  • BFS = shortest steps; DFS = explore / count groups; topological sort = dependencies; Dijkstra = weighted shortest path; union-find = dynamic groups.
  • All traversals are O(V + E).
