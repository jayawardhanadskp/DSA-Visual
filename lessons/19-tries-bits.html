Tries & bit tricks

Two smaller topics that appear regularly in interviews. A trie stores words so that words with the same beginning share the same path — perfect for autocomplete. Bit manipulation treats a number as a row of 0s and 1s, and gives a few very neat tricks.

Part A — Tries

1. 👀 A tree of letters

Each node is a dict of letter → child node, plus a flag "a word ends here". "car", "cat" and "cart" share the path c → a. A green ✓ node marks the end of a word.

Where you've seen it The search bar in your phone's contacts, a code editor's autocomplete, and a spell checker all need "which words start with what I typed?". A trie answers in O(length of the prefix), no matter how many words exist.
🧩 Template: trie with nested dicts 
root = {}

def insert(word):
    node = root
    for ch in word:
        node = node.setdefault(ch, {})   # go down, creating if needed
    node["$"] = True                     # word ends here

def walk(text):                          # the node for this prefix, or None
    node = root
    for ch in text:
        if ch not in node:
            return None
        node = node[ch]
    return node

# search(word):      (n := walk(word)) is not None and "$" in n
# starts_with(pre):  walk(pre) is not None

Signals: prefix, autocomplete, "starts with", dictionary of words, wildcard search, searching many words in a grid (LC 212).

Part B — Bits

2. Binary in 2 minutes

Computers store integers in binary: each position is a power of two. 13 = 8 + 4 + 1 = 0b1101.

x = 13
print(bin(x), x.bit_count(), int("1101", 2))   # 0b1101, three 1-bits, back to 13
print(f"{x:08b}")                               # padded to 8 digits
print(x & 1)          # last bit: 1 → odd
print(x >> 1, x << 1) # 6 (÷2), 26 (×2)
print(x & (1 << 2))   # is bit 2 set? (4 → yes)
TrickMeaning
x & 1is x odd?
x ^ x == 0, x ^ 0 == xXOR cancels pairs → "find the single one"
n & (n - 1)removes the lowest 1-bit → count bits, power of two
n & -nkeeps only the lowest 1-bit
1 << k2ᵏ; a "mask" with only bit k set
mask >> i & 1is item i in the subset encoded by mask? (all 2ⁿ subsets = masks 0 … 2ⁿ − 1)
