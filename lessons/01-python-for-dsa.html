Python for DSA (for a Dart developer)

You don't need all of Python for DSA — you need about 20% of it, very well. This lesson fixes the "broken basics" by comparing everything with Dart, and by showing what Python does in memory.

🎯 After this lesson you can
  • write loops, lists, dicts, sets, functions and classes without looking things up
  • explain what b = a really does (the #1 source of DSA bugs)
  • use slicing, comprehensions, enumerate, zip, sorted(key=…)
  • know the DSA toolbox: deque, heapq, Counter, defaultdict, bisect
Every grey code box below with a ▶ Run button is live Python Change it and run it. Break it on purpose. Reading Python doesn't teach Python — typing does.

1. Same program, two languages

Dart
int countBig(List<int> nums, int limit) {
  var count = 0;
  for (final x in nums) {
    if (x > limit) {
      count++;
    }
  }
  return count;
}

void main() {
  print(countBig([3, 8, 12], 5));
}
Python
def count_big(nums, limit):
    count = 0
    for x in nums:
        if x > limit:
            count += 1
    return count



print(count_big([3, 8, 12], 5))
  • No braces, no semicolons. A colon : starts a block, and the indentation (4 spaces) is the block. Wrong indentation = different program.
  • No types needed (you can add hints: def count_big(nums: list[int], limit: int) -> int:). No var/final — just assign.
  • snake_case names, not camelCase. No main() — top-level code just runs.
  • No ++: use count += 1.

3. Loops

range(stop), range(start, stop) and range(start, stop, step) make number sequences. The stop is never included. enumerate gives you the index and the value together (Dart: list.asMap().entries or indexed).

Dart
for (var i = 0; i < n; i++) {}
for (var i = n - 1; i >= 0; i--) {}
for (var i = 0; i < n; i += 2) {}
while (lo <= hi) {}
Python
for i in range(n): ...
for i in range(n - 1, -1, -1): ...
for i in range(0, n, 2): ...
while lo <= hi: ...

break and continue work like in Dart. zip(a, b) walks two lists side by side.

for i in range(5, 0, -1):
    print(i, end=" ")
print()
names = ["Ann", "Bo", "Cy"]
ages = [31, 25, 40]
for name, age in zip(names, ages):
    print(name, age)
for i, name in enumerate(names):
    if i == 1:
        continue
    print(i, name)

Slicing: a[start:stop:step]

Slicing makes a new list (a copy of that part). Start is included, stop is not — same as range. Any part can be left out.

a = [10, 20, 30, 40, 50, 60]
print(a[1:4])    # [20, 30, 40]
print(a[:3])     # first 3
print(a[3:])     # from index 3 to the end
print(a[-2:])    # last 2
print(a[::2])    # every second one
print(a[::-1])   # reversed copy
s = "python"
print(s[1:4], s[::-1])   # strings slice too

List comprehensions (Dart: map/where)

nums = [1, 2, 3, 4, 5, 6]
squares = [x * x for x in nums]                 # map
evens = [x for x in nums if x % 2 == 0]         # where
pairs = [(i, j) for i in range(3) for j in range(i)]  # nested loops
grid = [[0] * 4 for _ in range(3)]              # 3 rows x 4 cols
print(squares, evens, pairs, grid, sep="\n")

5. Strings

6. Tuples and unpacking

A tuple (1, 2) is a fixed, unchangeable list. It's used to return several values, as dict keys, and for unpacking:

point = (3, 4)
x, y = point            # unpacking (Dart 3 records: var (x, y) = point;)
a, b = 1, 2
a, b = b, a             # swap without a temp variable
print(x, y, a, b)

def min_max(nums):
    return min(nums), max(nums)   # returns a tuple
low, high = min_max([4, 9, 1])
print(low, high)
first, *rest = [1, 2, 3, 4]
print(first, rest)

7. dict and set (Dart Map and Set)

These are hash structures: looking up a key is O(1) on average, no matter how big they are. Lesson 04 shows how.

dict
ages = {"ann": 31, "bo": 25}
ages["cy"] = 40          # add / update
ages.get("zed", 0)       # 0 if missing
"ann" in ages            # True  (O(1))
del ages["bo"]
for name, age in ages.items():
    print(name, age)
list(ages.keys()), list(ages.values())
set
seen = set()             # NOT {} — that's a dict
seen.add(3)
3 in seen                # True  (O(1))
seen.remove(3)           # error if missing
seen.discard(3)          # no error
a, b = {1, 2, 3}, {2, 3, 4}
a & b, a | b, a - b      # and, or, minus

Keys must be immutable: numbers, strings, tuples. A list can't be a key — use tuple(the_list).

8. Functions

def greet(name, greeting="Hello"):        # default value
    return f"{greeting}, {name}!"

print(greet("Kasun"), greet("Kasun", greeting="Ayubowan"))

# functions inside functions (you'll use this for DFS and backtracking)
def count_paths(n):
    calls = 0
    def helper(i):
        nonlocal calls          # 'nonlocal' lets the inner function change 'calls'
        calls += 1
        if i >= n:
            return 1
        return helper(i + 1) + helper(i + 2)
    result = helper(0)
    return result, calls

print(count_paths(5))

# lambda = small anonymous function (Dart: (x) => ...)
words = ["kiwi", "fig", "banana"]
print(sorted(words, key=lambda w: len(w)))          # sort by length
print(sorted(words, key=lambda w: (-len(w), w)))     # longest first, then A→Z

10. ⚠️ References — the most important idea in this lesson

In Python, a variable is a label (name tag) stuck on an object, not a box that holds the value. b = a sticks a second label on the same object. Dart works the same way for lists and objects — but in DSA it matters a lot, so watch it happen:

The classic trap when making a 2-D grid:

And functions: a function receives a reference to the caller's list. Changing the list (append, items[0] = …) is visible outside. Re-assigning the name (x = 100) is not.

Rules of thumb
  • Need an independent copy of a list? a.copy(), a[:] or list(a). (For a list of lists: [row[:] for row in grid].)
  • In backtracking (lesson 16) you'll write result.append(path[:]) — copy, because path keeps changing.
  • Default arguments are created once: never write def f(x, seen=[]). Use seen=None and create it inside.

13. 📌 Summary

  • Indentation is the block. True/False/None, and/or/not, // and %, x += 1.
  • range and slices never include the stop.
  • Lists: end operations are O(1), front operations and in are O(n). dict/set lookups are O(1).
  • Variables are labels on objects. b = a doesn't copy. Make 2-D lists with a comprehension.
