Lesson 03 · Arrays & hashing

Arrays & strings

Most interview problems are about arrays (Python lists) and strings. Before learning tricks, understand what an array is in memory — then the costs from lesson 02 stop being things to memorise and start being obvious.

🎯 After this lesson you can
  • explain why indexing is O(1) but inserting at the front is O(n)
  • solve problems in one pass with "so far" variables
  • use a counting list ([0] * 26) for letters
  • walk a 2-D grid and its neighbours safely

1. What an array is

An array is a row of equal-sized slots, next to each other in memory. If the first slot is at address 1000 and each slot is 8 bytes, slot i is at 1000 + 8 × i. Python does that math and jumps straight there. That's why a[i] is O(1) — no searching.

Python list = Dart List = a "dynamic array" It keeps some extra free slots at the end. append uses a free slot (O(1)). When it runs out, it allocates a bigger block (about 1.125–2× bigger) and copies everything. That copy is rare, so on average append is still O(1) ("amortised O(1)").

2. 👀 Inserting in the middle

Python's insert does this in fast C code, but the work is the same: every element after the index moves one slot.

So insert(0, x) and pop(0) on a list of n elements move n elements. If you need fast operations at the front, use collections.deque (lesson 08).

3. Pattern: one pass with "so far" variables

Many array problems can be solved by walking once from left to right while remembering a summary of the past: the minimum so far, the best answer so far, a count so far… Ask yourself: "If I'm standing at index i, what do I need to know about everything before i?"

🧩 Template: one pass 
best = initial_value            # 0, float("inf"), nums[0], ...
summary = initial_summary       # what I remember about the past
for x in nums:
    best = update(best, x, summary)   # use the past to answer "what if it ends here?"
    summary = remember(summary, x)    # then add x to the past
return best

Signals: "maximum / minimum …", "best day", "so far", one answer from a whole list, O(n) required.

4. Pattern: counting with a list

When the values are small numbers or lowercase letters, a plain list can be a counter: index = the value, content = how many times we saw it. ord(ch) - ord("a") turns 'a'..'z' into 0..25.

Two words are anagrams exactly when their 26 counts are equal. A dict (Counter) does the same job for any kind of value — that's lesson 04.

5. Strings

  • A string is an immutable array of characters. Indexing and slicing work like lists. s[i] = … is an error.
  • To change characters, convert: chars = list(s) → edit → "".join(chars).
  • Build results in a list, then "".join(parts) (not += in a loop).
  • Useful: s.split(), " ".join(), s.isalnum(), s.lower(), s[::-1], ord/chr.
s = "hello world"
chars = list(s)
chars[0] = "H"
print("".join(chars))
print(s.split(), s.title(), s.count("o"), s.find("world"))
print([s[i:i + 3] for i in range(0, len(s), 3)])     # chunks of 3

6. 2-D grids

A grid is a list of rows: grid[r][c]. Many problems ask you to look at a cell's neighbours. Use a list of directions and always check the bounds (remember: negative indexes don't crash in Python, they wrap around!).

🧩 Template: neighbours in a grid 
rows, cols = len(grid), len(grid[0])
for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
    nr, nc = r + dr, c + dc
    if 0 <= nr < rows and 0 <= nc < cols:
        ...  # use grid[nr][nc]

You'll use this exact code again in graphs (lesson 15): islands, flood fill, shortest path in a maze.

7. Common mistakes

MistakeFix
Off-by-one: range(len(a) + 1) or a[len(a)]Valid indexes are 0 … len(a) - 1. Trace the first and last loop step by hand.
Removing items from a list while looping over itBuild a new list, or loop over a copy, or use the write-pointer pattern (lesson 05).
nums = … inside a function that must change the list in placeUse nums[:] = … or change elements by index.
Starting "smallest so far" at 0Start at nums[0] or float("inf").
Forgetting empty inputAlways ask: what if the list/string is empty? One element?

9. 📌 Summary

  • Arrays are slots side by side: index O(1), insert/remove in the middle or front O(n), append/pop at the end O(1).
  • Strings are immutable arrays of characters: build with a list + join.
  • "So far" variables turn many problems into one O(n) pass.
  • Grids: grid[r][c], a directions list, and a bounds check.
