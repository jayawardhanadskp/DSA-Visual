Greedy algorithms & intervals

A greedy algorithm makes the choice that looks best right now and never reconsiders. When it works, it's the simplest and fastest solution there is. The skill is knowing when it works — and intervals (meetings, ranges, bookings) are where greedy shines most.

  • check a greedy idea against a small counter-example before trusting it
  • solve interval problems with "sort, then sweep"

1. Greedy vs DP

GreedyDynamic programming
Ideapick the best-looking option nowtry all options for each sub-problem, keep the best
Speedusually O(n) or O(n log n)usually O(n²) or O(n × something)
Correct?only if a "greedy choice is always safe" argument existsalways (if the recurrence is right)

How to check a greedy idea: try to break it with a tiny example. Coins [1, 3, 4] and amount 6 break "biggest coin first" (4+1+1 vs 3+3). If you can't break it and can explain why the choice is safe ("taking this never makes things worse"), go greedy.

2. 👀 Kadane: the best contiguous sum

Walk once. At each number decide: carry the run you have, or start fresh here? If the run so far is negative it can only hurt, so drop it.

3. 👀 Jump game: only the farthest point matters

You don't need to know which jumps to make. Track the farthest index you could reach so far; if you ever stand beyond it, you're stuck.

4. 👀 Intervals: sort, then sweep

An interval is [start, end]. Almost every interval problem starts with sorting — then overlapping intervals sit next to each other and one left-to-right sweep handles everything.

🧩 Interval templates 
# merge overlapping
intervals.sort()                          # by start
merged = []
for start, end in intervals:
    if merged and start <= merged[-1][1]: # overlaps the last one
        merged[-1][1] = max(merged[-1][1], end)
    else:
        merged.append([start, end])

# keep the most non-overlapping → sort by END, keep the earliest-ending
# how many at the same time (rooms) → sort by start + min-heap of end times

Signals: meetings, bookings, ranges, "overlap", "merge", "minimum number of rooms / arrows / removals", timelines.

7. 📌 Summary

  • Greedy = best choice now, never undo. Fast, but prove it (or at least try to break it) first.
  • Kadane: drop a negative running sum. Jump game: track the farthest reach.
  • Intervals: sort by start to merge; sort by end to keep the most; heap of ends to count rooms.
