Backtracking

"Return all the ways…" — all subsets, all orderings, all valid boards. Backtracking builds a solution one choice at a time, explores everything that follows from that choice, then undoes the choice and tries the next one. It's a DFS over a tree of decisions.

🎯 After this lesson you can
  • draw the decision tree of a problem before coding
  • write the choose → explore → un-choose template from memory
  • tell subsets, combinations and permutations apart, and prune branches

1. The real-life picture

You're in a maze. At every fork, pick a path. If you hit a dead end, walk back to the last fork and try the next path. To find every exit, keep doing this until all paths are tried. Walking back is "backtracking"; remembering which way you took is the path.

2. 👀 Subsets: the decision tree

Each node of the call tree is a path (the choices so far). Every node is recorded as one subset. Watch path grow with append and shrink with pop — the shrinking is the "back" in backtracking.

🧩 Template: backtracking 
result = []
path = []

def backtrack(state):
    if is_complete(path):            # or: record at every node (subsets)
        result.append(path[:])       # COPY!
        return
    for choice in choices(state):
        if not valid(choice):        # pruning: skip hopeless branches
            continue
        path.append(choice)          # 1. choose
        backtrack(next_state)        # 2. explore
        path.pop()                   # 3. un-choose

backtrack(start_state)

Signals: "all subsets / combinations / permutations / partitions", "generate all valid …", "every way to …", puzzles (sudoku, N-Queens, word search), and small input sizes (n ≤ 15–20).

5. 👀 Pruning: N-Queens

Place one queen per row. Before placing, check if the square is attacked (column, or one of the two diagonals). If every square in a row is attacked, that whole branch is dead — undo the last queen and try the next column. Pruning is what makes backtracking fast enough.

Trick: all squares on one "\" diagonal have the same r - c, and on one "/" diagonal the same r + c. Three sets make the attack check O(1).

8. 📌 Summary

  • Backtracking = DFS over a decision tree: choose → explore → un-choose.
  • Record a copy of the path. Undo every change.
  • Subsets / combinations loop from start; permutations loop over everything unused.
  • Exponential by nature — pruning makes it practical.
