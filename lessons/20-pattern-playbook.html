3. All the templates on one page

# two pointers (opposite ends)
l, r = 0, len(a) - 1
while l < r:
    if good: return ...
    elif need_bigger: l += 1
    else: r -= 1

# sliding window (variable)
left = 0
for right in range(len(s)):
    add(s[right])
    while invalid():
        remove(s[left]); left += 1
    best = max(best, right - left + 1)

# prefix sums + dict
seen, run = {0: 1}, 0
for x in nums:
    run += x
    count += seen.get(run - k, 0)
    seen[run] = seen.get(run, 0) + 1

# monotonic stack
stack = []
for i, x in enumerate(nums):
    while stack and nums[stack[-1]] < x:
        j = stack.pop(); ans[j] = x
    stack.append(i)

# binary search: first True
lo, hi = 0, n
while lo < hi:
    mid = (lo + hi) // 2
    if ok(mid): hi = mid
    else: lo = mid + 1
# tree DFS
def dfs(node):
    if not node: return base
    l, r = dfs(node.left), dfs(node.right)
    return combine(node, l, r)

# BFS (graph / grid / tree levels)
seen, q = {start}, deque([start])
while q:
    node = q.popleft()
    for nei in neighbours(node):
        if nei not in seen:
            seen.add(nei); q.append(nei)

# heap of size k
for x in nums:
    heappush(h, x)
    if len(h) > k: heappop(h)

# backtracking
def bt(start):
    res.append(path[:])
    for i in range(start, n):
        path.append(a[i]); bt(i + 1); path.pop()

# DP (bottom-up)
dp = [base] * (n + 1)
for i in range(1, n + 1):
    dp[i] = best_of(dp[i - 1], dp[i - 2], ...)

# intervals
iv.sort()
for s, e in iv:
    if out and s <= out[-1][1]:
        out[-1][1] = max(out[-1][1], e)
    else: out.append([s, e])

4. Interview mode: the 45 minutes

MinutesDoSay out loud (example)
0–5Understand. Restate, ask about input size, duplicates, negatives, empty input, what to return."So I get an unsorted list of integers, can be negative, and return the indexes — is there always exactly one answer?"
5–10Examples by hand, including an edge case."For [2, 7, 11] and 9, I'd return [0, 1]. Empty list → no answer."
10–15Brute force + its Big-O. Then find the waste and name the pattern."Checking all pairs is O(n²). The waste is searching for the partner again and again — a dict makes that O(1)."
15–30Code cleanly. Explain as you go. Good names."seen maps value to index…"
30–38Test: trace your example through the code line by line (like a trace table!). Then edge cases."i = 0, x = 2, need = 7, not seen, store 2 → 0…"
38–45Complexity and trade-offs; possible follow-ups."O(n) time, O(n) space. If the input were sorted I could do O(1) space with two pointers."
Stuck in an interview? Say what you're thinking ("I'm considering a sliding window, but negatives break it…"). Go back to the brute force and look for repeated work. Try a smaller example. Ask "would sorting help?" and "what if I had a dict of…?". Silence is the only real mistake.

6. Your LeetCode plan

About 140 problems in the same order as this course. Many you have already solved here — on LeetCode, solve them again in their editor (that's your first review!). Aim for 1–2 a day; do the review list on the home page first.

7. How to keep going

📅 Daily

Reviews due (home page) → 1 new problem → write down the pattern + one sentence of "why" in a notebook.

⏱ Time box

20–30 minutes stuck → one hint → 15 more minutes → solution. Then retype it from memory and add it to your review list.

🗣 Practise talking

Once a week, solve a problem out loud as in section 4 — record yourself, or explain it to a friend.

🎯 Contests

After ~100 problems, try LeetCode weekly contests. Q1 and Q2 are usually the patterns from this course.
