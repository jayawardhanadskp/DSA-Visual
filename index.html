How to use this course

📂 Open it

Double-click index.html, or (recommended) in this folder run python3 -m http.server 8000 and open http://localhost:8000.

▶ Visualizers

Click a visualizer, then use → / ←. 🧠 Predict mode makes you guess the next line. ✏️ Edit & visualize runs your own changes.

🐍 Python in the browser

The practice editors run real Python (Pyodide). The first run downloads it once (~10 MB, needs internet), then it's cached. Ctrl/⌘+Enter runs tests.

🎬 Watch my code

A test fails and you don't know why? Press 🎬 under a problem to step through your code on the first test.

💻 Offline / VS Code

Every problem is also in workbook/: python3 workbook/05_two_pointers.py prints ✅ / ❌. Solutions are in workbook/solutions/.

💾 Progress

Your code, solved problems and review dates are saved in this browser (localStorage). Use the same browser each time.
